# Simple implementation of the Game of Life

Used it to teach my 8yo how to "play" the game.

Add "glider" to the CLI to show the glider pattern. Or create your own in code.

Usage:

- Hit **enter** to advance to the next generations.
- Type **CTRL+C** to exit.
